How to read it. Each hour shows temperature (feels-like beneath), chance of rain, and the wind — arrow points the direction the wind is blowing, sized text is speed in km/h, and it's colour-coded for how it hits you relative to your direction of travel. The wind badge on each leg is the average across the riding window.
Times are shown in each leg's local clock, with the Toronto-time equivalent beneath (watches stay on Toronto time to Summerside). Forecasts firm up as the date nears — anything more than ~7 days out is a low-confidence signal, so re-open this closer to the ride.
Share it: this is a single self-contained file — send the .html to teammates and they open it in any browser, or drop it on a link (e.g. GitHub Pages) for a permanent URL. It pulls fresh data every time it loads. No login, no key.
Weather: Open-Meteo (free, no API key). Leg coordinates are representative midpoints and are editable at the top of this file's script.
